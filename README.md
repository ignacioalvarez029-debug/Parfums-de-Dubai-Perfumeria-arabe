# Al Misk - Perfumería Árabe

Una página web elegante para una perfumería especializada en fragancias árabes tradicionales. El sitio presenta una colección exclusiva de perfumes inspirados en la rica herencia perfumera de Oriente.

## Características

- **Diseño Elegante**: Inspirado en la estética árabe con colores dorados y tipografías ornamentales.
- **Catálogo Interactivo**: Muestra líneas de productos como Oud, Musk, Rose y Amber.
- **Chat de WhatsApp Integrado**: Simulación de un chat en vivo para consultas.
- **Responsive**: Adaptable a diferentes tamaños de pantalla.
- **Animaciones Suaves**: Transiciones y efectos visuales para una experiencia inmersiva.

## Tecnologías Utilizadas

- **HTML5**: Estructura semántica.
- **CSS3**: Estilos avanzados con variables CSS, gradientes y animaciones.
- **Fuentes Google**: Cinzel Decorative, Cormorant Garamond y Raleway.
- **SVG**: Gráficos vectoriales para texturas y elementos decorativos.

## Cómo Usar

1. Clona el repositorio.
2. Abre `index.html` en tu navegador web.
3. Explora el catálogo y prueba el chat simulado.
